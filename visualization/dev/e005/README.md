# E-005 local reconstruction

The E-005 Dynamic Table mini scene uses the author's saved chapter-1 loop and camera from `../e002-control-panel-preview/table-preview.json`. It pins one TLE per spacecraft at the loop midpoint, then holds those elements throughout the loop. This differs intentionally from the full view, which selects the nearest dated TLE as playback proceeds. The local Library row reads its episode name and description directly from the live Episodes sheet; at the November 18 review, the description cell is still blank. The latest Library spot comments are archived in `../review-comments-round-9-archived.json`.

The published Episodes sheet supplies the object identifiers and chapter configuration on every load. At the November 17, 2026 review, E-005 has two provisional 168-hour chapters centered at **2022-01-08 04:24 UTC** and **2022-02-14 15:16 UTC**. The chapter navigation updates automatically as the sheet changes.

`data/41744.json`, `data/50321.json`, and `data/50322.json` are dated Space-Track GP_HISTORY extracts fetched for 2021-12-01 through 2022-05-01. `data/provenance.json` records their SHA-256 hashes and counts (11, 400, and 390). `fetch_history.py` can reproduce the acquisition with credentials in the environment; no credentials are stored here.

The local full view is `visualization/Viz/compare.html?dev=1&episode=E-005`. It propagates the nearest dated TLE per spacecraft at each playback time. All three spacecraft stay plotted; USA 270 is gold, the selected Shiyan target is gray, and the other target fades. The opening relative view centers the selected gray target. The ECI camera uses the normal of USA 270's orbital plane and shows its full orbit. The relative view expresses both Shiyan spacecraft in the selected target's rotating radial/along-track/normal frame by default. Playback, scrubbing, camera controls, source disclosures, two dynamic charts, and shared local spot comments are active. Playback crosses from chapter 1 to chapter 2 through the local time-transition overlay and resumes at chapter 2's start.

The earlier focused panel review is `visualization/dev/e005-panel-review/`. It shows only the E-005 control panel beside the E-002 local panel, with no visible 3D scene. Its approved panel treatments are now integrated into the full local E-005 route. The full route keeps the E-005-only spot editor.

The charts sample each chapter densely and use the nearest dated TLE for each object throughout, including when the TLE is older than 72 hours. They connect adjacent samples across nearest-TLE changes. The time axis moves left as playback advances. Minima and dwell use the same illustrative samples; the selected TLE epoch and signed age remain visible in each satellite's details. The E-005 default speed threshold is 10 m/s, and low-speed chart axes use m/s. The published site has not been deployed.

The **Camera workshop** button on the local full route opens eight relative-motion configurations: each chapter, each Shiyan target, and either the selected target or USA 270 as the frame origin. The review scrubber remains usable during playback; two-hour stops are the default, with one- and four-hour choices. Dashed and solid guides show the modeled path before and after the current moment. Dragging the globe keeps the camera in manual mode, and switching configurations carries the preceding camera frame forward. Saved angles and notes are stored in `saved-camera-views.json`; the workshop can export them with author-added key moments. No ECI angle requests are included because ECI uses the orbital-plane normal automatically.
